# Substitutions courantes (scaling matériel)

| Manquant | Remplacement |
|---|---|
| Rameur / vélo / course | Durée équivalente sur ce qui est dispo (400 m ≈ 90 s ≈ 500 m row ≈ 60 burpees rythmés) |
| Pull-ups | Ring rows, jumping pull-ups, négatives, bandes |
| Muscle-ups | 3 pull-ups + 3 dips par MU (équivalence approximative) |
| HSPU | Pike push-ups pieds surélevés, DB strict press |
| Corde | Tractions à la serviette, rope pulls lestés |
| Double-unders | Tuck jumps ou 2× single-unders (moins fidèle) |
| Wall ball | Thrusters DB/barre à ~2× le poids du ball |
| GHD sit-ups | Sit-ups ancrés, V-ups, hollow rocks |
| Barre olympique | Haltères / kettlebells : DB snatch, DB clean & jerk, DB thruster |
| Box | Sauts sur banc, step-ups lestés, tuck jumps |
