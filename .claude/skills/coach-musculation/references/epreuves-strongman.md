# Tableau des épreuves strongman

## Les six familles d'épreuves
| Famille | Épreuves types | Travail en salle |
|---|---|---|
| **Presse** | log press, axle press, circus dumbbell, block press | développé militaire, push press, barre épaisse, développé haltère lourd, triceps |
| **Deadlift** | car deadlift, 15" deadlift, axle deadlift, deadlift ladder | block pull, deficit, trap bar, prises épaisses, rack pull |
| **Squat / static** | frame squat, fat bar squat, squat pour reps | back/front squat, Zercher, séries de 10-20 reps |
| **Portage** | yoke, farmer's walk, duck walk, frame carry | portages lestés, safety bar walkouts, marches en fermier haltères, gainage anti-latéral |
| **Chargement** | atlas stones, sandbag over bar, keg toss | sandbag lourd, stone-lift patterns, hip hinge, back extension, tirage sol |
| **Traction / retournement** | truck pull, sled drag, tire flip | prowler/sled, power clean, hip thrust, mollets, sprints en côte |
